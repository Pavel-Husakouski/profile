# CV

Резюме — любой файл `<Имя> - <Роль>.md` в корне репозитория, например
`Павел Гусаковский - Nodejs-backend-fullstack.md`. Сборка даёт на каждое PDF с тем же
именем.

Новый вариант резюме — копия существующего md под новым именем; `justfile` правиться не
должен. Язык генератор определяет по заголовку `# Имя`: кириллица — русский, иначе
английский.

Имя, email, LinkedIn и телеграм написаны в markdown как есть. Телефон, город и формат
работы лежат в `.env` — в исходниках на их месте стоят плейсхолдеры, которые подклеивает
генератор.

## Пререквизиты
- `just` — раннер сборки;
- `chromium` — им печатается PDF (`make-pdf.py` возьмёт `google-chrome-stable`, `chromium` или `chrome`);
- `python` — скрипты сборки, сторонних библиотек не требуют;
- `nodejs`/`npm` — только для `just watch` (через `npx onchange`).

## Установка (Arch / Manjaro)

```sh
sudo pacman -S just
sudo pacman -S nodejs npm
sudo pacman -S google-chrome-stable
```

## Контакты

Они лежат в `.env` (шаблон — `.env.example`):

```sh
PHONE="+000(00)000-00-00"
EN_LOCATION="City, Country"
RU_LOCATION="Город, Страна"
EN_FORMAT="Office or remote"
RU_FORMAT="Офис или удалённо"
```

Кавычки обязательны: без них just спотыкается о пробел в значении.

Ключ без префикса — одно значение на оба языка, с префиксом `EN_`/`RU_` — своё на каждый;
генератор сначала ищет значение под префиксом своего языка, потом без него.

Имя в заголовке резюме написано как есть — плейсхолдером его держать незачем, язык резюме
и так задаёт форму имени. Имя файла выхлопа берётся из имени исходника.

Строка контактов целиком живёт в markdown, поэтому вся вёрстка — порядок, разделители,
какая ссылка с каким текстом — видна там, где её и правят. Email, LinkedIn и телеграм стоят
в ней открытым текстом, телефон и две подписи справа — плейсхолдерами, их заполняет
`scripts/contacts.py`:

```markdown
[you@example.com](mailto:you@example.com) · [LinkedIn](https://www.linkedin.com/in/your-handle/) · [{{PHONE}}](tel:{{PHONE_TEL}}) · [@your_handle](https://t.me/your_handle) · {{LOCATION}} · {{FORMAT}}
```

| Плейсхолдер | Что подставляется |
| --- | --- |
| `{{PHONE}}` `{{LOCATION}}` `{{FORMAT}}` | значение из `.env` как есть |
| `{{PHONE_TEL}}` | номер без разметки: `+00000000000` |

Телефон в ссылке — только `{{PHONE_TEL}}`: скобки из `+000(00)000-00-00` оборвали бы URL на
первой `)`, и половина номера утекла бы в видимый текст.

Плейсхолдер без значения в `.env` — ошибка сборки: резюме с буквальным `{{PHONE}}` хуже,
чем отсутствие резюме.

`{{EMAIL}}`, `{{LINKEDIN}}`, `{{TELEGRAM}}` и `{{TELEGRAM_URL}}` как плейсхолдеры
по-прежнему работают, если захочется вернуть их в markdown — тогда и значения возвращаются
в `.env`. `TELEGRAM` там можно писать и как `@handle`, и как ссылку — генератор приведёт к
нужному виду сам.

## Команды

| Команда | Что делает |
| --- | --- |
| `just` | PDF всех резюме |
| `just pdf <src> [out] [lang]` | PDF одного резюме |
| `just build [src]` | PDF одного исходника; без аргумента — всех |
| `just watch [src...]` | пересборка PDF на каждое сохранение; без аргументов — все резюме, включая добавленные на ходу |
| `just upload <file> [name]` | один файл на Google Drive |
| `just upload-all` | все PDF на Drive |
| `just publish` | `just` + `upload-all` |

`out` по умолчанию — имя исходника с расширением `.pdf`, `lang` — по заголовку.
